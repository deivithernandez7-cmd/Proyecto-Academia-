# Proyecto Academia

Una aplicación web desarrollada con **Django** para la gestión y administración de academias y cursos.

## 🚀 Características principales

- **Gestión de Academias:** Registro y administración de distintas academias.
- **Gestión de Cursos:** Control e inscripción de cursos interactivos.
- **Autenticación y Roles:** Sistema de usuarios para administradores, profesores y estudiantes.

## 🛠️ Tecnologías utilizadas

* **Backend:** Python / Django
* **Base de datos:** SQLite / PostgreSQL
* **Control de versiones:** Git & GitHub

## 📋 Requisitos previos

Asegúrate de tener instalado en tu sistema:
* Python 3.10+
* Git
